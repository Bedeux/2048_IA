# Tests du projet 2048_IA

Ces tests sont destinés à vérifier le fonctionnement de la classe `Board` qui permet de jouer au jeu 2048

## Prérequis

- Python 3.11+
- pip

### Installer les dépendances

Depuis la racine du projet :

```bash
pip install -r requirements.txt
```

## Lancer les tests

Le moyen le plus simple pour exécuter tous les tests est d'utiliser pytest

Depuis la racine du projet, lancez :

```bash
python -m pytest -q
```
